A linkedlist is a linear datastruture in which elements are stored in separate object called nodes.
Each node contains data and a reference (link) to another node.


A linkedlist node contains :
* Data : The value stored in the node.
* Next : A reference to the next node.

Type of LinkedList 
1> Single Linkedlist 
    Each node points to the next node only.

2> Doubly linkedlist
    Each node points to both the previous and next nodes.

3> Circular linkedlist
    The last node points back the first node instead of null.


How does linkedlist overcome the problem of array 
A linkedlist solve some of limitations of array specially when inserting or
 deleting element frequently.
